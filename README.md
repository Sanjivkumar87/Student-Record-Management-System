# Student-Record-Management-System
Console-based Student Management System developed using Core Java and OOP concepts with CRUD operations for managing student records.

A console-based Java application developed using Core Java and Object-Oriented Programming concepts to manage student records efficiently. The system allows users to add, view, search, update, and delete student information through a simple menu-driven interface.

Technologies Used
Java
Core Java
OOP Concepts
ArrayList
Features
Add Student
View Students
Search Student
Update Student
Delete Student
